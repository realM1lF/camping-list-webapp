# Spec: Packlisten-UI Polish

Datum: 2026-08-09  
Status: Freigegeben (Nutzer: „mach mal“)

## Ziel

Layout-Bugs im Item-Detail und der Liste beheben; eigene Zusage mit Anzahl steuern; Filter kompakter; Listenansicht: Kategorie (Default) + Kompakt.

## Entscheidungen

1. **Detail-Sheet Layout:** Titel ohne Mid-Word-Break; Kommentar-Bubbles ohne Abschneiden; Stepper-Zahlen ohne Überlappung; weniger vertikaler Ballast.
2. **Bring ich mit:** Bestehendes Layout behalten; runde +/− wie bei Benötigt. 0 = keine Zusage; + legt an / erhöht; − verringert / entfernt bei 0.
3. **Filter-Chips:** Kleiner, eine Zeile.
4. **Ansichten:** Default = Kategorie (normale Zeilen). Zweite = gleiche Gruppen, kompakter. Flache Status-Liste entfällt.

## Nicht-Ziele

Keine Redesigns der Sheet-Struktur, keine neuen Features außer Claim-Anzahl-UI.
